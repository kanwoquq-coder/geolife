# GeoLife GPS Trajectories 1.3

This repository provides a GitHub Release mirror of the GeoLife GPS Trajectories 1.3 dataset for scholarly access.

## Original source

The dataset was published by Microsoft Research Asia as part of the GeoLife project.

- Project page: https://www.microsoft.com/en-us/research/project/geolife-building-social-networks-using-human-location-history/tools/
